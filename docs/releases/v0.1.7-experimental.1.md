# PGRazor v0.1.7-experimental.1

Experimental release for ARM64 Android and MuMu.

## Events

- New **Events** screen in the Quick Menu, with settings grouped by event.
- **Halloween 2026:** enable **Open boxes and skip encounters** to automatically open visible map boxes, collect their rewards, and skip Pokemon encounter screens without catching. This opens all boxes, not only candy boxes.

## Other changes

- Rewrote the gameplay runtime in compiled native C++ and Java.
- Fixed buddy berry feeding on MuMu and Routes pausing during location updates.
- Reduced unnecessary inventory scans and fixed VGP pauses after unsent requests.

## Installation

Install **PGRazor.apk** over your existing PGRazor installation to preserve settings. One APK supports ARM64 Android phones and MuMu.

This build is experimental. Automated checks and MuMu verification passed; this release has not been retested on a physical Android phone.
