# PGRazor v0.3.5.1 (PGRazor_Pokematrix fork)

Built on [PGRazor v0.3.5](https://github.com/jpitty03/PGRazor/releases/tag/v0.3.5), with the fork changes from v0.3.4.1:

- Buddy Emotion overlay is a compact one-line badge; tap it for the full status.
- Smaller cooldown timer; with "Show local time" on, the local time is a small second line inside it.
- Gyms settings have a direct "Show Gym feeder map icon" switch.
- Virtual Go Plus has a "Show VGP status text" switch.
- Double-tap on the game map asks Walk or Teleport, with "Don't ask again".
