# v0.3.8.1

Fork release on top of upstream PGRazor v0.3.8 and Pokémon GO 0.439.0.

## Based on upstream v0.3.8

Upstream's Auto Rocket, in-app updater, global settings, favorite actions and the 0.439.0 game compatibility fixes are included. See `docs/releases/v0.3.8.md` and `v0.3.7.md`.

## Fork features carried over

- TM shortcuts on the Pokémon screen, VGP+ storage-tag rules (Catch only / Candy species / rare criteria / fallback berries), manual-catch berry rules, compact overlays, VGP status text, double-tap Walk/Teleport choice, and the settings dividers.
- Backup fixes: per-key validators for all tag-rule keys, a shared `PreferenceSchema` for exported preferences, and full default/custom export→import round-trip tests.
- Storage-tag membership changes now invalidate old VGP skip decisions; tags still loading no longer produce a definitive rejection.
- The player's full Pokémon storage is exposed as plain JSON for later features; Rocket counter cards allow copying exact CP values (`CP1234, CP2345, CP5678`) for manual selection in the game's search.

## New counter engine

- Shared `counter_engine` ranks your stored Pokémon against foes; gym, raid and Rocket adapters use the same scoring.
- New settings under Smart battling: **Use counter party in raids**, **Raid counter team size** (1–6) and **Show raid counter list**. All three are persisted, validated and round-trip tested.
- Device-verified: raid and saved-party grunt battles now pick counters through this code path.
