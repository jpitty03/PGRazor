# PGRazor v0.1.7-experimental.2

Experimental update for ARM64 Android and MuMu.

## Fixes and improvements

- Fix auto-battle actions not activating in Rocket, Gym, Raid, and Dynamax battles, including quick attacks, charged attacks, and Rocket shields. The relevant automation settings must be enabled.
- Keep autowalk's default at **50 stops**, while allowing a count up to all currently loaded nearby locations. The maximum updates with nearby availability; leave the count blank to select All.
- Reduce VGP inventory-cleanup waits by resuming when cleanup completes. Routine checks query selected item types, and large cleanup batches process in bounded steps.
- Prevent one missing box encounter-animation callback from permanently blocking subsequent box collection. Late encounter screens remain suppressed.

## Verification and known limitations

Battle automation was reported working on Android and MuMu. A 193-stop autowalk route was started and observed progressing on MuMu; automated tests cover 512 stops. The box-collector recovery passed native regression tests, but live pickup recovery remains unverified. Large inventory cleanup has fixture coverage; actual deletion still uses the game's broader descriptor list.

An intermittent Android startup crash remains under investigation. Box collection pauses if its bounded delayed-callback storage fills. This remains an experimental build.

## Installation

Install **PGRazor.apk** over your existing installation to preserve settings. One APK supports ARM64 Android phones and MuMu.
