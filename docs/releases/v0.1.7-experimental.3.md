# PGRazor v0.1.7-experimental.3

Experimental update for ARM64 Android and MuMu, using one APK.

## New features

- **VGP+**: configurable balls, ordered catching rules, berries and throw quality. Catch loaded spawns beyond the standard VGP distance limit, subject to server acceptance, and continue while in-game menus are open.
- **Auto-spin Gym discs** under **Virtual Go Plus > VGP+**: enable the option and start VGP. Spins loaded gyms of any team within 40 m while on the map, with bag-space checks and per-gym cooldown handling. The old gym-spin preference carries over.
- **Gym Slotter & Berry Feeder**: deploy eligible Gym-tagged defenders and feed surplus Nanab/Razz berries above reserves. Its draggable gym-and-berry icon controls both actions, with a compact status line. Cooldown stops the run; restart manually afterward.
- **Buddy Emotion Engine**: snapshots, petting, reserve-aware feeding with berry priority, optional gift collection, and an optional EP overlay. Replaces Auto feed buddy; walking and battles remain manual.
- **Batch evolution**: preview a tagged batch and costs, then evolve eligible Pokemon without the cutscene. Optional tag removal applies only after confirmed evolution; Stop prevents further requests.
- **World Map**: place search, a separate current-location marker, 14 hotspots, and Walk/Teleport actions on Stop, Gym and Raid details. Teleports show the estimated destination cooldown, including zero when no action is recorded.

## Fixes and improvements

- Gym auto quick/charged attacks now continue past the next-opponent countdown automatically. Manual exit or disabling those settings cancels continuation. Includes the earlier Rocket, Gym, Raid and Dynamax auto-battle fixes.
- Recheck nearby gyms promptly after temporary no-action results; fix deployment and feeding blocked by unreliable local closed-state data.
- Fix buddy care pausing after gifts or buddy changes, Quick Spin losing pending work during short stalls, native VGP encounter validation, and visible event boxes skipped by an extra expiry cutoff.
- Restore wild-catch cooldown history, group dependent settings coherently, and gray out disabled child controls without losing preferences.
- Refresh website feature guides and compact cooldown guidance.

## Using tags

**Gym defenders:** Create a `Gym` tag in Pokemon storage and tag eligible defenders. Enable Auto-deploy under Gym Slotter & Berry Feeder, then start its overlay near a friendly gym with an open slot. Leave lowest-CP fallback off to use tagged choices only. Favorites, the current buddy, injured/deployed Pokemon and other ineligible defenders are skipped. Deployment keeps the tag.

**Evolution:** Create an `Evolve` tag (or enter another tag name in Batch evolution), tag only Pokemon you want evolved, and select Preview batch. Review eligibility and costs before Start. Each Pokemon evolves once per batch. Optionally enable Remove this tag after each confirmed evolution; other tags and skipped entries are preserved. Activate any Lucky Egg yourself. If an error occurs, check storage before retrying because evolution may have succeeded even if tag removal failed.

## Verification and limitations

The release APK was installed and hash-verified on physical Android and MuMu. Gym deployment/feeding, batch evolution with tag removal, and gym next-battle continuation were user-confirmed on MuMu. Automated coverage includes 134 Python tests, Java/native boundary checks and 26 website browser tests.

Gym-disc spinning was also user-verified after its dispatch fix and move to VGP+. This does not confirm every gameplay scenario. Server eligibility, cooldowns and inventory limits still apply. This remains an experimental release; intermittent startup instability reported previously is not claimed resolved.

## Installation

Install **PGRazor.apk** over the existing installation to preserve settings. One APK supports ARM64 Android phones and MuMu. See **SHA256SUMS.txt** for integrity verification.
