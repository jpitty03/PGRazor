# PGRazor v0.3.6.1 (fork)

Built on PGRazor v0.3.6 (keep-IV cutoff, candy quest filter, session stats, VGP+ lure/PokéStop/Route spawns, gym automation fixes), with the fork's changes:

## New features

- **TM shortcuts on the Pokémon screen.** A Fast TM / Charged TM icon sits before each move's power number on both move tabs. Tapping it starts the game's own TM flow, so the game's confirmation still appears. With no TM of that kind the icon is grey and a tap says so. Settings › IV display › "TM shortcuts on the Pokémon screen".
- **VGP+ tag rules.** "Catch only" and "Candy species" can use your Pokémon storage tags (Browse by category › "Pokémon storage tags"). A tag covers the whole candy family and follows your tags as you change them in the game.
  - "Candy species berry" (Pinap by default) for candy species.
  - "Rare Pokémon: Ultra Ball + rare berry": choose what counts as rare (Legendary/Mythical/Ultra Beast, shiny, shundo, 100%, nundo, IV threshold, event costume, special background, an ultra-rare species list) and the berry (Silver Pinap, Golden Razz…).
  - "Also catch rare Pokémon outside Catch only".
  - Overlay button (Pinap / Silver Pinap) to switch the tag rules on and off.
- **Compact overlays.** Smaller Buddy Emotion badge (`♥ 28 ★ ⏱11m`), smaller cooldown timer with the local time inside it, Gym feeder map icon switch (Settings › Gyms), VGP status text switch (icon only).
- **Double-tap on the map: Walk or Teleport**, with "Don't ask again".
- **Manual catch berry follows the tag rules.** On a manual encounter the berry overlay shows, and feeds, the tag rules' berry: for a rare Pokémon the rare berry, then Golden Razz, then the candy berry; for a candy family the candy berry. Out of stock or no rule: your berry priority list.
- **Settings layout.** Hairline separators and spacing between each option + description pair across Settings and its dialogs. VGP+ now lists Catch only, Catch only shinies, then Candy species, with clearer descriptions.
- **Google sign-in through the browser.** Facebook sign-in cannot work on a re-signed APK ("Invalid key hash").

## Other

- TM shortcuts only work while a Pokémon page is open, at most every 100 ms.

## Fixes

- VGP+ never saw a wild Pokémon's IVs (the map's copy has none), so IV-based rules could not match. It now reads the encounter response, as Shundo Sniper does.
- The IV line on the Pokémon screen was drawn behind the 3D model when the screen was opened from the Pokédex.
- The IV line kept the old level after a power-up.
- After changing VGP+ tag rules, Pokémon skipped under the old rules were ignored for an hour; they are now considered again at once.
