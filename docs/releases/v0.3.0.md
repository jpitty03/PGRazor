# PGRazor v0.3.0

## New features

- **Auto Throw:** Throws has a default-off toggle that throws for you using your throw settings, selected ball and berry, with Always Hit. With Catch on map, tapping a Pokémon catches it without opening the encounter. A tap made while VGP+ is busy waits for it to finish. Reward Pokémon from Go Pass and research are left for you to throw.
- **Auto-Raid:** Automation can find nearby matching raids, travel to them, wait for enough players, battle using your auto-attack settings, and attempt the bonus catch. Run it from Automation -> Auto-Raid.
- **Go Wild November 2026:** Events has separate, default-off Safari Ball preferences for Mighty Pokémon in VGP+ and Auto Ball. Normal ball settings apply when Safari Balls are unavailable or the encounter is ineligible.
- **PGRazor Root (experimental):** A separate installer loads PGRazor into the official game with logs, settings backups, account switching, an on/off switch that takes effect on the next game launch, and a Reboot button. Installing or updating the module needs one reboot; switching on or off afterwards does not.

## Improvements & fixes

- Skip cutscenes closes the "New level unlocks" and other feature-unlock cards, and a hidden level-up screen no longer blocks taps for up to 30 seconds.
- Auto incubate or Skip cutscenes skips the post-hatch Eggs page by completing the hatch directly. Manually opened Eggs pages remain accessible. More cutscenes are skipped.
- Added a startup fallback for phones where features sometimes did not load until the game was restarted. Exported logs now record the reason if it still happens.
- Quick Catch adds experimental acceleration for Dynamax catch, breakout and flee animations.
- Berry priorities can also be selected in Settings under Catch & summary.
- Pokémon lists support category filters, including Legendary, Mega-capable, and second- or third-stage evolutions, with selection by name.
- Shundo Sniper waits for account and gameplay readiness before teleporting, shows what it is waiting for, and stops and asks for a restart when the map stops loading Pokémon. It also uses less data while waiting.
- Account restoration waits briefly for the game to resume before restarting it, avoiding a blocked handoff during sign-in.
- Run logs keep more history and include more account, settings and hatch details. PGRazor no longer leaves 5 MB of old files behind each time the game starts.
