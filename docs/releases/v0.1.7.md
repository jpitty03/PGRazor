# PGRazor v0.1.7

Stable release for ARM64 Android and MuMu, using one APK.

## Features

- **VGP+**: configurable balls, berries, throw quality and catching rules, background catching while menus are open, and optional nearby gym-disc spinning. Server range and eligibility checks still apply.
- **Gym Slotter & Berry Feeder**: deploy Gym-tagged defenders and feed surplus berries, with separate choices controlled by one gym-and-berry overlay. Nearby gym actions use an 80 m base range and respect cooldowns and server results.
- **Buddy Emotion Engine**: ordered berry priorities, reserve-aware feeding, petting, snapshot requests, optional gifts and an EP overlay. Walking and battles remain manual.
- **Automation** in Settings and Quick Menu: Mass Evolve, a manually started Daily Incense Session, and a single Remote Gym Feeding batch for gyms you defend. These tasks do not restart automatically.
- **Mass Evolve**: preview eligibility and costs for a tagged batch, evolve once per Pokemon, and optionally remove the selected tag after confirmed evolution.
- **World Map**: search businesses, parks, landmarks and addresses; view your current-location marker; choose from 14 hotspots; Walk or Teleport from place details. Teleports show estimated destination cooldowns, including zero without recorded actions.
- **Idle walking**: walk a 10 m-radius circle when idle, with manual movement taking priority and speed zero pausing it. Walking-distance credit remains game-dependent.
- **Events screen**: enable collection of loaded event boxes and dismiss encounter screens. Candy-only identification is not offered.
- Compiled native/Java gameplay runtime with stripped production binaries.

## Fixes and improvements

- Includes Rocket, Gym, Raid and Dynamax auto-battle fixes and automatic continuation past the gym next-opponent countdown.
- Recover gym discovery after viewing a gym, deployment-to-feeding transitions, delayed berry inventory updates, and buddy feeding after restocking or switching buddies.
- Start buddy snapshot sessions using the game's buddy photo context and server-adjusted session time before requesting completion.
- Keep gym-disc activity under VGP+; keep the manual Keep All encounter button independent of background transfer settings.
- Restore catch cooldown history, selected-item inventory cleanup, Quick Spin recovery and visible event-box collection.
- Fix map automation stopping during long sessions. Bound session-log retention, reduce repeated logging and avoid unnecessary hidden-settings and overlay UI work.
- Refresh feature guides, screenshots, cooldown guidance and the Spawn booster lag warning.

## Using tags

**Gym defenders:** Create a `Gym` tag in Pokemon storage and apply it to eligible defenders. Enable Auto-deploy under Gym Slotter & Berry Feeder, then start the overlay near a friendly gym with an open slot. Leave lowest-CP fallback off to restrict selection to tagged defenders. Favorites, your buddy, injured/deployed Pokemon and other ineligible choices are skipped. Deployment preserves the tag.

**Evolution:** Create an `Evolve` tag, or enter another tag name in **Automation > Mass Evolve**. Tag only Pokemon you want evolved, preview the batch and costs, then press Start. Each Pokemon evolves once per batch. Optional tag removal affects only confirmed evolutions and preserves other tags. Activate any Lucky Egg manually. After an error, check storage before retrying because evolution may have succeeded even if tag removal failed.

## Known limitations

- Intermittent Android startup crashes in Unity/JNI remain unresolved. Restarting recovered the observed session; this release does not claim a crash fix.
- The updated buddy snapshot request path passes native tests, but snapshot-heart credit has not yet been confirmed in game.
- Daily Incense Session stops its walk and VGP when it detects a loaded Galarian bird, attempts the normal encounter tap and alerts you. The live bird handoff remains unverified. Catch manually; there is no automatic throw or Master Ball path, and no guaranteed spawns.
- Server eligibility, cooldowns and inventory limits still apply. Automated boundary tests do not establish every live gameplay scenario.

## Installation

Install **PGRazor.apk** over your existing installation to preserve settings. One APK supports ARM64 Android phones and MuMu. **SHA256SUMS.txt** provides the APK checksum; **build-info.json** identifies the source and verification results.
