# Third-party components

PGRazor's MIT license applies to its original code, not the following components or the original game.

- The opt-in native pilot statically links [Dobby](https://github.com/jmpews/Dobby/tree/0932d69c320e786672361ab53825ba8f4245e9d3), under Apache-2.0. Its pinned source is downloaded only on request, verified by SHA-256, and its LICENSE is included in pilot APKs under `assets/pgrazor/native-notices/`. Normal packages do not include this optional component.

- The GitHub Pages website bundles **React, React DOM, and Scheduler**, copyright Meta Platforms, Inc. and affiliates, under the [MIT license](website/public/licenses/react.md). The notice ships with the static website. Development tools and their versions are recorded in `website/package-lock.json`.
- The website's world-map screenshot contains map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), with attribution retained in the capture.

- **Frida Gadget 17.24.2** is fetched from the [official Frida release](https://github.com/frida/frida/releases/tag/17.24.2) when explicitly requested, with GitHub-provided SHA-256 verification. It is not committed here. See [Frida's source and licenses](https://github.com/frida/frida).
- **frida-java-bridge**, distributed with frida-tools 14.10.4, is retained under `pgrazor/vendor/`. The local derivative reproduces upstream commit `302a588881b40cba300bcf3acfd35deeb3888ee5`. Upstream declares `LGPL-2.0 WITH WxWindows-exception-3.1`. The original bundle, exact patch script, hash provenance, distribution license, and [notice](pgrazor/vendor/NOTICE.txt) are included. Embedded dependency notices remain in the bundle.
- Android SDK build tools and the JDK are external build prerequisites and are not redistributed in source artifacts.
- Pokémon GO code, artwork, names, and assets remain with their respective rights holders. Original game builds are user-supplied private inputs. Selected map icons are copied unchanged and base-species names are extracted from [PokeMiners/pogo_assets](https://github.com/PokeMiners/pogo_assets); their pinned upstream paths and hashes are recorded in `pgrazor/assets/map-icons/provenance.json`. These images and names are game content, excluded from PGRazor's MIT license. The upstream repository attributes the artwork to The Pokémon Company and Niantic.

- Feed base-species sprites are copied unchanged from [PokeAPI/sprites](https://github.com/PokeAPI/sprites), pinned at `97a7832d307311c0e1c6ea9035308bf80cc94f81`. Paths and SHA-256 hashes are recorded in `pgrazor/assets/feed-icons/provenance.json`. Pokémon artwork belongs to its respective rights holders and is excluded from PGRazor's MIT license.

- The optional build-time DEX bridge rewriter uses **dexlib2 2.5.2** (BSD-3-Clause), **Guava 27.1-android** and **failureaccess 1.0.1** (Apache-2.0), and **JSR-305 3.0.2** (BSD-3-Clause). These tools are not embedded in APKs. Exact Maven URLs and SHA-256 pins are recorded in `tools/dex_bridge/dependencies.json`; upstream sources are https://github.com/JesusFreke/smali and https://github.com/google/guava.

- The separately built, opt-in **libpgrazor-art.so** (`PGRAZOR_COMPILED_LOCATION=1`, requiring the native pilot and compiled Java bridges) statically links **LSPlant 6.4** at `7217ac6f41e2bda549e4acb54e632abb03e5ccaf` (LGPL-3.0), **DexBuilder** at `9d57844a301077abf4c29e061b2458c56a363c8f` (its pinned `LICENSE` is LGPL-3.0), **parallel-hashmap** at `65775fa09fecaa65d0b0022ab6bf091c0e509445` (Apache-2.0), **XZ Embedded** at `ae63ae3a36ed01724674e8f3d750dc47bf125410` (0BSD permission notice; formerly public-domain code), and Dobby at `0932d69c320e786672361ab53825ba8f4245e9d3` (Apache-2.0). Sources: https://github.com/LSPosed/LSPlant, https://github.com/LSPosed/DexBuilder, https://github.com/greg7mdp/parallel-hashmap, https://github.com/tukaani-project/xz-embedded, and https://github.com/jmpews/Dobby. The ART build uses its separately pinned NDK toolchain; it does not change the gameplay core's NDK.
  When this opt-in path is selected, the packager includes stripped process-ABI libraries under `assets/pgrazor/<abi>/libpgrazor-art.so` and all five original license notices under `assets/pgrazor/art-notices/`. Full build provenance remains only in the local package report, outside the APK. The receipt records exact source pins, source hashes, library hashes and local relink inputs. Retain the complete `pgrazor/build/art/<session>/` CMake object/static-archive tree, link maps, unstripped outputs, matching PGRazor sources/build scripts, and pinned dependency sources for LGPL relinking and corresponding-source distribution. Debug/object files are retained locally, not copied into APK assets. This documents the optional packaging behavior; it does not claim that a production release containing the ART bridge has been built, distributed, or runtime-validated.
